# Изменения в unofficial v1 (первый публичный релиз)

Для кого: пользователи порта и разработчики, которым нужно знать, что изменилось после предыдущей сборки, описанной в этом
репозитории («classic v2», 2026-10-29), и почему.

| | classic v2 (2026-10-29, не публиковалась) | unofficial v1 (2026-11-09) |
|---|---|---|
| Ядро | 7.1.2 | 7.1.13 + правки ath11k, q6voice и панели (`kernel/patches/`) |
| Дерево устройств | DTB в стиле downstream | DTB из `sm7325-samsung-m52xq.dts` (стиль апстрима) + локальные узлы, включён RTC (`device-tree/`) |
| dtbo | не менялся | заменяется на `dtbo-frag` (один безвредный фрагмент, загрузчику он нужен для этого DTB) |
| Образ | снимок одного телефона с его личными данными, 3 чанка | чистый образ: без личных данных, ключей и закрытых прошивок, 2 чанка |
| Zip | не публиковался | `ubuntu_touch_classic_26.04-m52xq-mainline-v1-UNOFFICIAL.zip`, md5 `a3343884846751530f4a590e23e9275e` |

Нужна чистая установка: Format Data, как описано в README.

## Установщик и образ

- **В zip нет закрытых прошивок.** ADSP, модем, IPA, Venus, zap-шейдер GPU, прошивка Bluetooth и конфиги датчиков копируются
  при установке с разделов самого телефона, как в порте postmarketOS.
- Ключи SSH создаются при первой загрузке (`m52xq-ssh-hostkeys.service`, запускается до `sockets.target`; прежний порядок
  давал цикл, и systemd иногда выкидывал `ssh`). machine-id и адрес Bluetooth у каждого телефона свои.
- Установщик сам пишет dtbo (`dtbo-frag`). Загрузка после другого порта больше не уходит в цикл перезагрузок.
- `/home` и `/opt/click.ubuntu.com` лежат на разделе userdata (`run-m52xq\x2drootsrc-userdata.mount`); хуки click
  возвращают папку пользователю (`click-system-hooks.service.d`).
- `~/.config` создаётся для пользователя до любых служб сессии (`tmpfiles.d/m52xq-user-config.conf`); раньше папка
  принадлежала root, и настройки не сохранялись.
- Bluetooth был заблокирован при первой загрузке: в образе лежали сохранённые состояния rfkill с другого телефона. Теперь всё
  разблокировано, а `m52xq-bt-firmware` ждёт разблокировки без конвейера, который завершался только на следующем событии rfkill.
- Подкачка zram 3 ГБ (`m52xq-zram.service`).

## Ядро

- **Звонки: переключение громкая/разговорный без новых голосовых сессий** (`m52xq-q6voice-in-place-device-switch.diff`).
  Аудио-DSP иногда падал, и телефон перезагружался, когда во время звонка создавалась новая голосовая сессия. Теперь
  устройство переключается на месте, как в downstream-драйвере: пауза голосового тракта, `VSS_IVOCPROC_CMD_SET_DEVICE_V3`,
  формат, калибровка, запуск. Параметр `q6voice.device_switch` (включён по умолчанию).
- **Экран: нет вспышки при пробуждениях по сети** (`m52xq-panel-sleep-while-brightness-0.diff`). При выходе из сна ядро будило
  панель с полной яркостью раньше, чем система успевала оставить её тёмной. Теперь панель спит, пока яркость 0, и просыпается,
  когда яркость выставлена.
- **Выключенный Wi-Fi действительно спит** (`m52xq-ath11k-radio-off-power-save.diff`). При выключенном радио прошивке WCN6750
  никто не говорил перейти в энергосбережение, и она не спала всю ночь. Драйвер AHB теперь шлёт `POWER_SAVE_ENTER` при сне с
  выключенным радио (в тесте 86 с сна из 90, раньше 0).
- В дереве устройств включён RTC (`pmk8350_rtc`): будильник будит телефон из сна.
- Переход с 7.1.2 на стабильный 7.1.13 с правками порта postmarketOS v2 (имя АЦП датчика батареи, прерывания Type-C во сне,
  выгрузка ath11k).

## Звонки, контакты и звук

- **Исправлено падение ModemManager при подключении мобильного интернета** (`build/modemmanager/0104-…`):
  `transaction_complete()` вызывал обработчик после освобождения транзакции. Падал до 8 раз за загрузку, терялись входящие
  звонки, переключался режим SIM. Кандидат в апстрим ModemManager.
- **Исправлено падение звонилки при открытии во время звонка** (`build/kpeople`): два потока работали с одним соединением базы
  KPeople (имя контакта и аватар) без блокировки. Кандидат в апстрим KPeople.
- Входящий звонок: кнопки звонилки нажимаются. Когда звонилка на переднем плане, уведомление о звонке скрыто, но мелодия
  играет; когда нет, показывается уведомление с кнопками.
- Полоска звонка открывает работающую звонилку (фокус вместо второго запуска, от которого она падала) и показывает время
  звонка и номер или имя контакта.
- Громкая и выключенный микрофон сбрасываются в конце звонка (`plasma-dialer-0012`); следующий звонок начинается в разговорном.
- Тишина в громкой после нескольких переключений: маршрут усилителя повторяется, если TFA9878 не запустился
  (`m52xq-voicecall`, `m52xq-tfa-guard`); `m52xq-audio-rescue` перепривязывает звуковую карту, если после загрузки её нет.
- Контакты из адресной книги Lomiri выгружаются для звонилки (`m52xq-contacts-sync`); кнопка «Добавить контакт» в звонилке
  открывает адресную книгу (`plasma-dialer-0013`).
- Ширина окна USSD и кнопки звонка в альбомной ориентации (`plasma-dialer-0010`).

## Оболочка и система

- **Язык из мастера применяется везде.** Стоковый мастер не сохранял язык, если в списке не было пункта для текущей локали.
  Теперь он сохраняет его всегда (`Wizard/Pages/10-welcome.qml`). Генератор окружения пользователя systemd и drop-in для
  индикаторов ставят `LANG`/`LANGUAGE` по учётной записи, поэтому шторка, Настройки и приложения следуют выбору.
- Язык по умолчанию английский, клавиатура по умолчанию английская, код разблокировки из 4 цифр `1111`; мастер всегда
  показывает шаг Wi-Fi и заранее выбирает цифровой код.
- Блокировка экрана: сначала гаснет подсветка, потом рисуется экран блокировки (без вспышки экрана блокировки перед погашением).
- Телефон больше не блокируется сам при закрытии окна пароля Wi-Fi или уведомления.
- Звук через Bluetooth не даёт телефону уснуть, как и звук через динамик.
- Morph Browser продолжает играть медиа в фоне; у часов есть альбомная разметка; меню перезагрузки и SIM переведены.
- Будильник: `lomiri-indicator-datetime` вместо индикатора Ayatana (он читает будильники приложения часов), пробуждение по
  будильнику RTC.
- TELEports работает: в образе есть `libssl1.1` и `qml-module-lomiri-pushnotifications`.

## Камера

- Цифровой зум до 4x (щипок или ползунок) для видоискателя, фото и видео, сделан в источнике GStreamer (`build/m52xqcamsrc`).
- Фото 64 Мп без нехватки памяти: меньше буферов для кадров от 24 Мп (`build/libcamera/patches/0012-…`, примерно на 670 МБ
  меньше) плюс zram.
- Исправлено падение при переключении фронтальная/основная (обработчик libcamerasrc на освобождённом состоянии); снимки после
  переключения больше не повёрнуты.
- Ползунок зума помещается в альбомной ориентации.
